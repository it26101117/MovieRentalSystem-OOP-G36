#  CineRent – Movie Rental System

CineRent is a Java-based Movie Rental and Review Management System developed using **Object-Oriented Programming (OOP)** concepts.

##  Features
- User registration and login
- Movie browsing and searching
- Movie rental management
- Online payments with PayHere
- Movie ratings and reviews
- Admin dashboard
- Recently watched movies

## Technologies
- **Backend:** Java 19, Spring Boot 3.5.16, Jakarta Servlets
- **Frontend:** JSP, HTML, CSS, JavaScript
- **Build Tool:** Apache Maven
- **Data Storage:** Text files

##  OOP Concepts
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction

##  CRUD Operations
- **Create:** Add movies, rentals and reviews
- **Read:** View movies, rentals and reviews
- **Update:** Edit movie details, rental status and reviews
- **Delete:** Remove movies and reviews

## ️ Run the Project
1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Configure Java 19 and Maven.
4. Configure required payment environment variables.
5. Run `MovieRentalApplication.java`.
6. Open the application in your browser.
